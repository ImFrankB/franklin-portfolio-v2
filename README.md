# Empty but Live: Ship a Blank Page

**Project Purpose:** Create and deploy a deliberately minimal portfolio page. This is only the empty-but-live milestone, not the final portfolio.

**Chosen Stack:** React, Vite, TypeScript, Tailwind CSS, GitHub, Vercel

## Commands

- **Installation:** `npm install`
- **Development:** `npm run dev`
- **Production Build:** `npm run build`

## Vercel Deployment Instructions

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Vercel will automatically detect the Vite framework and configure the build settings.
4. Deploy the project.
